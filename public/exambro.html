Panduan Sinkronisasi Google Sheets

1. Format Kolom (Wajib Berurutan):

A (Kolom 1) B (Kolom 2) C (Kolom 3) D (Kolom 4)
NIS NAMA LENGKAP KELAS PASSWORD

*Jangan gunakan header/judul kolom pada baris pertama jika ingin data langsung terbaca.

2. Cara Publikasi Link:

  • 1 Klik menu File > Share > Publish to web
  • 2 Pilih tab Link, ubah "Entire Document" menjadi Sheet1
  • 3 Ubah "Web Page" menjadi Comma-separated values (.csv)
  • 4 Klik Publish, salin linknya dan tempel di bawah ini.
